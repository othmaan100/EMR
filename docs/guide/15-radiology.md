# Radiology and imaging

**Menu:** Clinical → Radiology · **Used by:** radiographers, radiologists; doctors view signed reports

## Workflow

| Status | Who | What happens |
|---|---|---|
| Requested | Doctor | Examination ordered with the clinical indication |
| Scheduled | Radiographer | A date and time is set (optional) |
| Performed | Radiographer | The examination is done (payment checked if "pay before service" is on) |
| Completed | Radiologist | Report written and **signed** — released to the doctor and patient |

## Performing an examination

1. Open **Radiology** (tabs: To perform, To report, Reported today), select the order and optionally **Schedule** it.
2. When done select **Mark examination performed**. The report starts from the examination's normal template.
3. Upload images or documents (JPEG, PNG or PDF) if not using a PACS. Images are stored privately and only shown to authorised staff.

## Reporting

The radiologist writes **findings** and **impression**, saves, and selects **Sign & release**. Signed reports can be printed; a "results ready" SMS is sent if enabled.

## PACS (digital image server)

If the hospital has connected a PACS (see Integrations), each order shows its **accession number** — the imaging order number (e.g. IMG2026-000045). Enter or select this number at the X-ray, CT or ultrasound machine. When the images reach the PACS, the order links to them automatically within about five minutes (or select **Check PACS now**), is marked performed if it was not already, and a **View images** button opens the viewer.
