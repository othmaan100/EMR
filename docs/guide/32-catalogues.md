# Clinics, wards, catalogues and insurers

| Menu (Administration) | What you maintain |
|---|---|
| Clinics | Name, code (used in queue numbers), department, location, whether patients see a nurse first (triage), clinic type (general, dental, eye, physiotherapy) |
| Wards & Beds | Wards (type, sex, department, daily bed-charge service) and their beds; bed status (available, cleaning, out of service) |
| Clinical Catalogues | Billable services, lab tests (with result fields and normal ranges), imaging examinations, drug formulary, vaccines, surgical procedures, theatres and general store items |
| Insurance / HMOs | Payers: code, type (insurance or corporate), coverage %, contact, whether a PA code is required on claims |
| Price List | Standard prices and payer-specific tariffs (see Billing) |

Catalogue items are **deactivated, never deleted**, because past records refer to them. A deactivated item can no longer be ordered or charged.

Large catalogues and price lists can be loaded from spreadsheets with **Data Import**.
